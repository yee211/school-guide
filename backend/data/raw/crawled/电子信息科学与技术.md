# 电子信息科学与技术

> 长沙工业学院 · 2024-06-14

**专业概述**

本专业对接新一代半导体和人工智能及传感器产业链，与中电数科科技有限公司、三一重工股份有限公司、蓝思科技股份有限公司等行业龙头企业开展深入产教研学融合合作，培养具有理想信念、职业道德、社会责任感、合作交流和学习能力，掌握电子信息科学与技术基础理论与应用技术，具备创新、研发和工程实践能力，能够不断学习并具有一定特长专长的“有理想、重基础、多口径、强应用”的应用型高素质专门人才。

**核心课程**

电路分析、模拟电子技术、数字电子技术、单片机原理与应用、信号与系统、半导体器件物理、高频电子线路、集成电路制造工艺、通信网络基础、集成电路版图设计。

**就业方向**

可在集成电路、电子技术、信息处理等相关应用领域从事研究开发、工程设计、运营维护、技术管理等工作。

**实验条件**

机器视觉控制实验室

大学物理(光学实验室)

数字电子实验室

嵌入式开发实验室
