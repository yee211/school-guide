# 人工智能

> 长沙工业学院 · 2025-06-24

人工智能专业依托于计算机科学与技术专业的学科背景，立足长沙人工智能与传感器产业链，聚焦智能算法开发、AIoT技术集成、行业智能化转型三大产业方向。现有专任教师10人，具有教授(含其他正高级)职称教师2人、具有副高职称3人、具有硕士及以上学位的比例为100%。此外，还有3名具有行业背景的产业导师(其中1人为博士，2人为硕士)。现与华为、长城信息、比邻星、科大讯飞、蓝思科技、智擎等公司建立了深度产教研合作关系。

核心课程：机器学习、深度学习、数字图像处理、自然语言处理、计算机视觉与模式识别、机器人编程、大模型原理与应用、人工智能伦理。

就业方向：毕业生面向智能制造、智慧城市等重点领域，可在企事业单位从事AI智能体工程师、嵌入式AI开发工程师、智能系统集成工程师等岗位工作，胜任人工智能系统的设计开发、运维管理、技术迭代及数据合规保障等全周期任务，为区域数字经济高质量发展提供人才支撑。
